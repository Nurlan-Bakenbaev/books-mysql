# Авторский учебный план системного администратора 2026

Это мой авторский курс для тех, кто хочет освоить системное администрирование с нуля и последовательно перейти к работе с реальной инфраструктурой. Я собрал открытые учебные материалы и документацию, выстроил из них программу и дополнил её объяснениями, примерами, лабораторными работами и проверкой знаний.

Программа ориентирована на практические навыки, которые нужны системному администратору в 2026 году: Windows Server и Linux, сети, управление доступом, виртуализация, облака, безопасность, резервное копирование, мониторинг и автоматизация. Основа обучения — понимание устройства систем, самостоятельная диагностика и умение восстановить работающий сервис.

**Автор проекта:** [Nurlan-Bakenbaev](https://github.com/Nurlan-Bakenbaev) · **[Открыть курс](https://nurlan-bakenbaev.github.io/books-mysql/)**

Каждый урок содержит цели, теорию, схему, практический пример, пошаговую лабораторию, ожидаемый результат, диагностику, самопроверку и ссылки на материалы по теме. В расширенных уроках есть самостоятельные задания с подсказками и решениями. Лаборатории по безопасности выполняются на собственном или явно разрешённом учебном стенде; ограничения и порядок отката указаны рядом с действиями.

Для Security+ доступен индекс **121 темы Professor Messer** с уникальными публичными video ID, авторским русским объяснением, правилом и примером. Все темы имеют одного основного владельца среди **37 практических уроков**; покрыты введение и 28 objectives, включая 4.9. Это не 121 самостоятельная лаборатория. Названия и ID взяты из `IsaacMToast/security-plus-checklist` на commit `5414f6989ad34b5d6a80f704617e019a2a1e4b95`; транскрипты не копировались, воспроизведение всех видео не подтверждено.

Для Security+ добавлен учебный итоговый экзамен: **30 оригинальных вопросов** по пяти доменам SY0-701, результат и подробные объяснения после отправки ответов. Учебный проходной порог — 24 из 30 (80%); это порог тренажёра, отдельный от шкалы сертификационного экзамена.

Отдельная карьера **Network Engineer** построена по тематике [roadmap.sh/network-engineer](https://roadmap.sh/network-engineer): пять последовательных уровней, 20 уроков, RFC, Wireshark, FRRouting, Linux networking, WireGuard, NetBox, Ansible и Python. Для роста добавлены маршруты Network+, CCNA, JNCIA-Junos и CCNP Enterprise. Учебная последовательность адаптирована для курса; происхождение материалов и границы проверки описаны в [документе источников](docs/network-engineer-sources.md).

## На каких материалах основан курс

Я использую материалы из открытого доступа: официальную документацию, бесплатные курсы, стандарты и открытые GitHub-репозитории. Источники привязаны к конкретным урокам, чтобы можно было углубиться в тему и сверить объяснение с документацией.

В программе используются Microsoft Learn и лаборатории MicrosoftLearning, документация Linux и сетевых инструментов, Exam Objectives CompTIA и видеокурс Professor Messer, NIST CSF 2.0 и SP 800-61r3, NIST NVD, CISA KEV, MITRE ATT&CK, OWASP Cheat Sheet Series, ASVS, WSTG, Juice Shop, WebGoat и Nmap. Уроки Security+ являются самостоятельными материалами; на каждом есть ссылка на исходную страницу курса Professor Messer, но индивидуальные URL видео для каждой темы в этой среде проверить не удалось.

Авторская часть проекта — структура обучения, объяснения, учебные сценарии и задания. Внешние материалы остаются работами их авторов и доступны по ссылкам в библиотеке курса. Содержание ориентировано на изучение технологий и практику; результаты обучения зависят от самостоятельной работы со стендом.

## Как устроено обучение

- **Полный navbar:** Карта, Профессии, Курсы, Библиотека, Практика, Сертификации, Обзор. Network Engineer остаётся в каталоге. Карта профессии доступна по `?view=career-map`, старый `#landing-map` поддерживается.
- **Основной курс:** семь блоков с распределением 3 / 5 / 6 / 6 / 4 / 4 / 3. У каждого из 31 основного урока шесть разделов: бизнес-контекст, архитектура, пошаговая практика, три диагностических сценария, SecOps и 2–3 самостоятельных ТЗ. Старые темы не удалены: 17 дополнительных доступны по прежним ID.
- **Проверка знаний:** 38 видимых модулей по 10 вопросов, всего 380 вопросов в модульных попытках. Один автоматический вопрос и семь письменных заданий в каждом из 171 урока; критерии открываются после ввода ответа. Самооценка отделена от автоматического балла. Security+ сохраняет отдельный экзамен 30 вопросов.
- **Практика:** девять отдельных лабораторий, включая Ubuntu/systemd/HTTP 403/restore. У каждого шага есть ожидаемый результат, проверка и диагностика; каталог связывает практику всех уроков с курсом.
- **Личный кабинет:** основной курс, последний урок, позиция чтения, дни занятий, отдельные отметки лабораторий, письменные ответы и история результатов. JSON экспорт/импорт объединяет отметки и сохраняет неизвестные старые ID; ошибки записи показываются явно. Ключ `sysadmin-path-2026-progress` сохранён, новые данные хранятся в `sysadmin-path-2026-learning-v1` и `sysadmin-path-2026-assessments-v1`.
- **Поиск и чтение:** Fuse.js по метаданным, поиск по полному тексту и 121 видеотеме, словарь из 31 термина, Shiki, якоря и печать/PDF. Все уроки не разбиты на отдельные data bundles: дальнейшая оптимизация загрузки возможна.
- **Дизайн:** увеличенная сфера из 24 цветных логотипов, всегда обращённых к зрителю. GSAP управляет плавным вращением, увеличением выбранной иконки и мягким возвратом в орбиту. Наведение, фокус клавиатуры или касание открывают краткое описание; остальные иконки продолжают движение. На фоне главного экрана показан путь сигнала между двумя сетями через коммутаторы, маршрутизаторы, интернет и межсетевой экран. На телефоне схема складывается в два ряда. Обе анимации учитывают reduced-motion и останавливаются вне экрана и в скрытой вкладке; кнопки остановки сферы нет. Верхняя цветная линия этапов и ответвления имеют отдельную паузу.
- **Видео:** English выбирается при открытии урока; русский вариант доступен для 38 ранее подобранных уроков. Новые основные темы без проверенного ролика честно показывают отсутствие встроенного видео.


## Локальный запуск

Нужны Node.js 22.12+ и npm. Из корня репозитория:

```sh
cd frontend
npm ci
npm run dev
```

Приложение построено на React и Vite. Оно работает как статический сайт и не требует серверной базы данных.

## Проверки

Из каталога `frontend`:

```sh
npm test
npm run lint
npm run typecheck
npm run build
```

Перед сборкой Zod автоматически проверяет структуру учебных данных, ссылки на существующие источники, варианты и индексы ответов, распределение вопросов экзамена и метаданные русских видео. Проверки данных дополняют содержательную проверку текста по источникам.

Браузерные тесты Playwright и axe-core проверяют меню, поиск, экзамен, карту, переключение видео, доступность, мобильную вёрстку и сохранение прогресса:

```sh
npx playwright install --with-deps chromium
npm run test:e2e
```

Для cloud-среды с установленным Chromium:

```sh
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e
```

Команда собирает приложение и запускает preview автоматически. Внешнее воспроизведение YouTube в браузерных тестах не проверяется. При ошибках отчёты сохраняются в `frontend/playwright-report` и `frontend/test-results`.

## Публикация

[GitHub Pages workflow](.github/workflows/pages.yml) запускает проверки при отправке в `main` и публикует `frontend/dist` после их успешного завершения. В настройках **Pages → Build and deployment** используется **GitHub Actions**.

Существующая учебная карта доступна по `?view=roadmap`, отдельные уроки — по `?lesson=ID`. Старые адреса и сохранённые отметки прогресса поддерживаются при обновлениях.
