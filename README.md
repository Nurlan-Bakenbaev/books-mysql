# Путь системного администратора 2026

Интерактивная русскоязычная SPA/PWA для последовательного обучения системному администрированию. В приложении опубликовано 89 отдельных уроков: 31 урок основной карты, 9 по безопасности Windows, 30 в неофициальном треке AZ-104, 9 по безопасности Linux и 10 практических лабораторий по этичному хакингу и защите. Темы охватывают сети и виртуализацию, Linux и Windows Server, Azure, автоматизацию, мониторинг, hardening, расследование и восстановление.

Боковое меню показывает прогресс каждого трека и следующий урок. Основная карта изображена как маршрут с соединёнными точками, статусами этапов и раскрываемыми шагами. На мобильных устройствах меню открывается отдельной кнопкой; анимации учитывают системную настройку уменьшения движения. Старый ключ прогресса `sysadmin-path-2026-progress` сохранён, поэтому обновление не сбрасывает отметки пользователя.

Каждая тема открывается на отдельной странице, например `?lesson=ip-addressing`, и включает цели, объяснение, схему, практическую ситуацию, пошаговый разбор с проверкой и диагностикой, лабораторию, самопроверку, ссылки на материалы и рекомендуемое англоязычное видео. В подходящих темах есть полные исполняемые примеры, окно терминала с учебным выводом, макет интерфейса и практические задания с подсказками и решениями. Уроки `server-deployment`, `ad-ds`, `gpo` и `bash` дополнены углублённым разбором и расширенной практикой. Каждый из шести этапов, трек Windows, трек Azure и все пять модулей курса по книге содержат итоговый тест; ответы тестов не сохраняются после перезагрузки.

### Учебные треки

Неофициальный трек **AZ-104** завершён: идентификация и governance, хранилище, ARM/Bicep, VM и масштабирование, App Service, ACI и Container Apps, VNet/NSG/DNS/peering/routes, балансировка, Network Watcher, Azure Backup, Site Recovery, Azure Monitor и Action Groups. Структура дополнительно сверена с 13 открытыми лабораториями репозитория `MicrosoftLearning/AZ-104-MicrosoftAzureAdministrator`, снимок от 24 сентября 2026 года. Это авторский учебный курс, а не материал Microsoft и не гарантия сдачи экзамена; актуальный study guide, цены и интерфейс нужно сверять у Microsoft.

Трек **«Безопасность Linux»** проходит пользователей и sudo, SSH с сохранением доступа, firewall, обновления, модель угроз, journald/auditd, SELinux/AppArmor, baseline/hardening и восстановление. Изменения SSH, firewall, sudo и MAC сопровождаются второй сессией, консолью, проверкой синтаксиса и точной процедурой отката.

Трек **«Этичный хакинг и защита»** начинается с письменного scope и изолированного стенда, затем проходит OSINT, Nmap, перечисление сервисов, web-security, password hashing, Linux privilege paths, безопасность AD и отчёт с retest. Все действия предназначены только для собственных систем или явно разрешённых целей. Каждый урок показывает, какие события увидит защитник и как устранить первопричину.

Часть видео подобрана по смежным темам и привязана к ближайшему по смыслу уроку; доступность роликов на YouTube зависит от автора и региона и автоматически не проверяется.

Три встроенных тренажёра помогают рассчитать IPv4/CIDR, разобрать упрощённый путь пакета и правило firewall, а также потренировать несколько команд в виртуальном Linux-терминале. Они работают в браузере, не отправляют реальные пакеты и не выполняют команды ОС. Рядом приведена инструкция по установке официального Cisco Packet Tracer и первой сетевой лаборатории; сам Packet Tracer в сайт не встроен.

Библиотека — часть учебного маршрута, а не список репозиториев: карточка показывает аннотацию, ключевой вывод, связанные уроки и конкретный фокус чтения. Внешняя ссылка остаётся первоисточником для углубления. Объяснения, схемы и лаборатории приложения написаны самостоятельно. Внешние материалы и доступность YouTube могут меняться; видеоссылки тематически подобраны, но их доступность по региону автоматически не проверяется.

Встроенная читалка PDF.js показывает выбранный на устройстве PDF с оглавлением, поиском и переходом по страницам. Для ссылок путеводителя откройте свой экземпляр книги Jennifer Davis «Modern System Administration». К 21 главе курса есть русскоязычные объяснения, примеры и отдельные адреса, например `?chapter=compute`; это не полный перевод книги. При переходе между страницами в рамках приложения выбранный PDF остаётся открыт, но после перезагрузки файл нужно выбрать снова. Прогресс, тема и последняя страница сохраняются в браузере на текущем устройстве.

## Разработка

Требуются Node.js и npm. Из каталога `frontend`:

```sh
npm ci
npm run dev
```

Для проверки и сборки:

```sh
npm test
npm run lint
npm run typecheck
npm run build
```

Содержательные тесты проверяют полноту каждого урока, уникальность идентификаторов, ресурсы, схемы, walkthrough, quiz и сохранение прежних идентификаторов прогресса. Ручная браузерная проверка должна охватывать главную карту, мобильное меню и по одному уроку каждого нового трека.

## Развёртывание

Дашборд — статическое приложение без API и обязательной серверной базы. Manifest и service worker делают приложение устанавливаемым; навигация использует network-first, а версионированные assets кешируются без замораживания старого HTML. Для публикации в корне или подкаталоге используется относительный базовый путь Vite. Workflow `.github/workflows/pages.yml` запускает tests, lint, typecheck и build при отправке в `main`, а затем публикует `frontend/dist` через GitHub Pages. В **Settings → Pages → Build and deployment** должен быть выбран **GitHub Actions**.
