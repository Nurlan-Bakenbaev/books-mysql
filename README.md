# Путь системного администратора 2026

Интерактивная дорожная карта, глоссарий, домашние лаборатории и рекомендации по сертификациям. Прогресс и тема сохраняются в браузере на текущем устройстве.

## Разработка

Требуются Node.js и npm. Из каталога `frontend`:

```sh
npm ci
npm run dev
```

Для проверки и сборки:

```sh
npm run lint
npm run build
```

## Развёртывание

Дашборд — статическое приложение: настройте корневой каталог сборки `frontend`, команду установки `npm ci`, команду сборки `npm run build` и каталог публикации `dist`. API и база данных для дашборда не нужны. Если сайт публикуется в подкаталоге (например, GitHub Pages по пути `/books-mysql/`), задайте соответствующий `base` в конфигурации Vite перед сборкой. Хостинг и автоматический деплой в репозитории пока не настроены.
