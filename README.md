# Путь системного администратора 2026

Интерактивная дорожная карта системного администратора на русском языке: 31 урок в шести этапах, отдельный трек из девяти уроков по безопасности Windows и трек подготовки к Microsoft Azure AZ-104. Темы охватывают сети и виртуализацию, Linux и сервисы, Windows Server, гибридное облако, автоматизацию, мониторинг и реагирование на инциденты. Шаги маршрута раскрываются с анимацией, которую можно отключить системной настройкой уменьшения движения.

Меню сгруппировано по назначению: «Старт», «Обучение» (путь сисадмина, безопасность Windows, Azure AZ-104), «Практика» (тренажёры, домашние лабы), «Материалы» (библиотека, база знаний, книга как необязательный сворачиваемый блок) и «Сертификации».

Каждая тема открывается на отдельной странице, например `?lesson=ip-addressing`, и включает цели, объяснение, схему, практическую ситуацию, пошаговый разбор с проверкой и диагностикой, лабораторию, самопроверку, ссылки на материалы и рекомендуемое англоязычное видео. В подходящих темах есть полные исполняемые примеры, окно терминала с учебным выводом, макет интерфейса и практические задания с подсказками и решениями. Уроки `server-deployment`, `ad-ds`, `gpo` и `bash` дополнены углублённым разбором и расширенной практикой. Каждый из шести этапов, трек Windows, трек Azure и все пять модулей курса по книге содержат итоговый тест; ответы тестов не сохраняются после перезагрузки.

### Трек AZ-104: что опубликовано

Каркас трека повторяет структуру программы Microsoft Learn AZ-104 (26 тем в пяти разделах). Сейчас с полными лекциями, лабораторными, разбором и тестом опубликованы 6 тем раздела «Идентификация и управление»: основы Microsoft Entra ID, пользователи и группы, архитектура Azure, Azure Policy, Azure RBAC и самообслуживание сброса пароля. Остальные 20 тем (хранилище, вычисления, сети, резервное копирование и мониторинг) перечислены в сворачиваемом блоке «Следующие темы AZ-104 — пока в разработке» и будут добавляться поэтапно; в трек попадает только тема, у которой есть готовый урок. Это неофициальный конспект, а не материал или подготовка от Microsoft. Отдельные треки «Безопасность Linux» и «Этичный хакинг» ещё в разработке и в интерфейсе пока не опубликованы.

Часть видео подобрана по смежным темам и привязана к ближайшему по смыслу уроку; доступность роликов на YouTube зависит от автора и региона и автоматически не проверяется.

Три встроенных тренажёра помогают рассчитать IPv4/CIDR, разобрать упрощённый путь пакета и правило firewall, а также потренировать несколько команд в виртуальном Linux-терминале. Они работают в браузере, не отправляют реальные пакеты и не выполняют команды ОС. Рядом приведена инструкция по установке официального Cisco Packet Tracer и первой сетевой лаборатории; сам Packet Tracer в сайт не встроен.

Библиотека объединяет открытые книги, курсы, документацию и сообщества с указанием языка и условий доступа. Объяснения и схемы приложения написаны самостоятельно, а не скопированы из источников. Трек Windows — авторский курс по материалам Microsoft, а не официальный курс или сертификат; некоторые облачные лаборатории могут требовать лицензии и расходов. Внешние материалы, доступность видео, условия Cisco и версии меняются, поэтому сверяйте их с первоисточниками. Практику выполняйте в изолированной среде и не публикуйте секреты.

Встроенная читалка PDF.js показывает выбранный на устройстве PDF с оглавлением, поиском и переходом по страницам. Для ссылок путеводителя откройте свой экземпляр книги Jennifer Davis «Modern System Administration». К 21 главе курса есть русскоязычные объяснения, примеры и отдельные адреса, например `?chapter=compute`; это не полный перевод книги. При переходе между страницами в рамках приложения выбранный PDF остаётся открыт, но после перезагрузки файл нужно выбрать снова. Прогресс, тема и последняя страница сохраняются в браузере на текущем устройстве.

## Разработка

Требуются Node.js и npm. Из каталога `frontend`:

```sh
npm ci
npm run dev
```

Для проверки и сборки:

```sh
npm test
npm run lint
npm run typecheck
npm run build
```

## Развёртывание

Дашборд — статическое приложение: настройте корневой каталог сборки `frontend`, команду установки `npm ci`, команду сборки `npm run build` и каталог публикации `dist`. API и база данных для дашборда не нужны. Для публикации в корне или подкаталоге используется относительный базовый путь Vite. Workflow `.github/workflows/pages.yml` проверяет и собирает приложение при отправке в `main`, а затем публикует `frontend/dist` через GitHub Pages. В настройках репозитория откройте **Settings → Pages → Build and deployment** и выберите **GitHub Actions** в поле **Source**. После смены источника запустите workflow **Build and deploy Pages** через **Actions → Run workflow** для ветки `main`, если автоматический запуск ещё не завершился. Пока выбран вариант Deploy from a branch, Jekyll не публикует собранный дашборд; корневой `_config.yml` только исключает исходники и зависимости из его обхода.
