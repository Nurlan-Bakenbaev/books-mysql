# Путь системного администратора 2026

Интерактивная русскоязычная SPA/PWA для последовательного обучения системному администрированию. Публичный адрес открывает отдельный лендинг, а учебное приложение разделено на адресуемые страницы: обзор (`?view=overview`), основной путь (`?view=roadmap`), курсы, лаборатории, тренажёры, библиотеку, словарь, сертификаты и книги. В приложении опубликовано 107 отдельных уроков: 31 урок основной карты, 8 по компьютерным технологиям, 9 по безопасности Windows, 30 в треке AZ-104, 9 по безопасности Linux, 10 по этичному хакингу и защите и 10 в авторском курсе CompTIA Security+ · SY0-701.

Боковое меню группирует учебные маршруты, практику и библиотеку, автоматически раскрывает активную группу и сворачивается до панели иконок. Выбранный режим хранится локально. Основная карта изображена как один последовательный маршрут с соединёнными точками, текстовыми статусами этапов и раскрываемыми шагами. На мобильных устройствах меню открывается отдельной кнопкой и блокирует прокрутку фона; анимации учитывают системную настройку уменьшения движения. Старый ключ прогресса `sysadmin-path-2026-progress` сохранён, поэтому обновление не сбрасывает отметки пользователя. Старые адреса `#overview`, `#roadmap`, `?view=dashboard`, `?lesson=` и `?chapter=` продолжают работать.

Каждая тема открывается на отдельной странице, например `?lesson=ip-addressing`, и включает цели, объяснение, схему, практическую ситуацию, пошаговый разбор с проверкой и диагностикой, лабораторию, самопроверку, ссылки на материалы и рекомендуемое англоязычное видео. В подходящих темах есть полные исполняемые примеры, окно терминала с учебным выводом, макет интерфейса и практические задания с подсказками и решениями. Уроки `server-deployment`, `ad-ds`, `gpo` и `bash` дополнены углублённым разбором и расширенной практикой. Каждый из шести этапов, трек Windows, трек Azure и все пять модулей курса по книге содержат итоговый тест; ответы тестов не сохраняются после перезагрузки.

### Учебные треки

Неофициальный трек **AZ-104** завершён: идентификация и governance, хранилище, ARM/Bicep, VM и масштабирование, App Service, ACI и Container Apps, VNet/NSG/DNS/peering/routes, балансировка, Network Watcher, Azure Backup, Site Recovery, Azure Monitor и Action Groups. Структура дополнительно сверена с 14 открытыми лабораториями репозитория `MicrosoftLearning/AZ-104-MicrosoftAzureAdministrator`, снимок от 24 сентября 2026 года. Это авторский учебный курс, а не материал Microsoft и не гарантия сдачи экзамена; актуальный study guide, цены и интерфейс нужно сверять у Microsoft.

Трек **«Безопасность Linux»** проходит пользователей и sudo, SSH с сохранением доступа, firewall, обновления, модель угроз, journald/auditd, SELinux/AppArmor, baseline/hardening и восстановление. Изменения SSH, firewall, sudo и MAC сопровождаются второй сессией, консолью, проверкой синтаксиса и точной процедурой отката.

Трек **«Этичный хакинг и защита»** начинается с письменного scope и изолированного стенда, затем проходит OSINT, Nmap, перечисление сервисов, web-security, password hashing, Linux privilege paths, безопасность AD и отчёт с retest. Все действия предназначены только для собственных систем или явно разрешённых целей. Каждый урок показывает, какие события увидит защитник и как устранить первопричину.

В начале уроков используются популярные короткие объяснения продолжительностью до 15 минут. Доступность роликов на YouTube зависит от автора и региона.

Раздел лабораторий содержит пошаговые работы для собственного стенда: подготовку, последовательность действий и команд, ожидаемый результат, проверку, диагностику и откат. Опасные изменения выполняются только после создания snapshot и проверки резервного пути доступа.

Библиотека — часть учебного маршрута, а не список репозиториев: карточка показывает аннотацию, ключевой вывод, связанные уроки и конкретный фокус чтения. Каждый урок и каждая точка карты дают прямой переход к связанным материалам. Объяснения, схемы и лаборатории приложения написаны самостоятельно. 10 ноября 2026 года выполнена HTTP-проверка 96 учебных URL: исправлен устаревший адрес AppArmor; 94 адреса ответили успешно, а сайты Cisco NetAcad и nftables не ответили из среды проверки, поэтому их официальные адреса оставлены с явным указанием внешнего источника. Доступность YouTube зависит от автора и региона.

## Разработка

Требуются Node.js и npm. Из каталога `frontend`:

```sh
npm ci
npm run dev
```

Для проверки и сборки:

```sh
npm test
npm run lint
npm run typecheck
npm run build
```

Содержательные тесты проверяют полноту каждого урока, уникальность идентификаторов, ресурсы, схемы, walkthrough, quiz, совместимость старых URL и сохранение прежних идентификаторов прогресса. Браузерная проверка охватывает лендинг, обзор, карту, лаборатории, страницу урока, мобильное меню, отсутствие горизонтального переполнения и сохранение свёрнутого sidebar на ширинах от 320 до 1440 px.

## Поиск, примеры и проверка данных

Иконка меню в верхней панели сворачивает/разворачивает боковую навигацию на компьютере и открывает её на мобильном устройстве. Панель остаётся доступной при прокрутке; состояние настольной панели сохраняется, но не скрывает курсы в мобильном меню.

Кнопка поиска в верхней панели и сочетание **Ctrl+K / Cmd+K** открывают поиск по всем урокам, терминам и источникам. Fuse.js поддерживает опечатки; поиск в библиотеке и глоссарии использует тот же механизм. Источник открывается в новой вкладке, термин — в своей карточке, урок — на отдельной странице.

Shiki подсвечивает PowerShell, Bash, Python, YAML и JSON, включая Python/YAML/JSON внутри shell heredoc. Грамматики загружаются по необходимости при появлении примера на экране. Кнопка копирования сохраняет исходный текст без разметки; код не выполняется сайтом.

Zod проверяет обязательные поля уроков, терминов и лабораторий, уникальность ID, ссылки на существующие источники и структуру экзамена. Проверка автоматически выполняется перед сборкой и останавливает её при ошибке. Она проверяет данные, а не фактическую истинность объяснений:

```sh
npm run validate:content
```

Playwright проверяет production-сборку в настольном и мобильном Chromium: поиск, меню, экзамен, подсветку/копирование и старый localStorage-прогресс. axe-core проверяет доступность основных страниц, поиска и подсвеченного кода; страницы проверяются в светлой и тёмной темах. Запуск из `frontend`:

```sh
npx playwright install --with-deps chromium
npm run test:e2e
```

В cloud-среде с установленным системным Chromium можно обойтись без скачивания браузера:

```sh
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e
```

Команда сама собирает приложение и запускает preview для тестов. При ошибке сохраняются screenshot и trace в игнорируемых `test-results/`, HTML-отчёт — в `playwright-report/`. Внешние видео исключены из браузерного smoke test. Проверки выполняются в GitHub Actions до публикации Pages; тестовые отчёты загружаются при ошибке.

## Развёртывание

Дашборд — статическое приложение без API и обязательной серверной базы. Manifest и service worker делают приложение устанавливаемым; навигация использует network-first, а версионированные assets кешируются без замораживания старого HTML. Для публикации в корне или подкаталоге используется относительный базовый путь Vite. Workflow `.github/workflows/pages.yml` запускает tests, lint, typecheck и build при отправке в `main`, а затем публикует `frontend/dist` через GitHub Pages. В **Settings → Pages → Build and deployment** должен быть выбран **GitHub Actions**.
