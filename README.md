# Путь системного администратора 2026

Интерактивная дорожная карта, глоссарий, домашние лаборатории и рекомендации по сертификациям. Встроенная читалка PDF.js показывает выбранный на устройстве PDF целиком, с оглавлением, поиском и переходом по страницам. Для ссылок путеводителя откройте предоставленный экземпляр книги Jennifer Davis «Modern System Administration» в читалке. Путеводитель содержит пояснения на русском; оригинал книги — на английском. Прогресс, тема и последняя открытая страница сохраняются в браузере на текущем устройстве.

## Разработка

Требуются Node.js и npm. Из каталога `frontend`:

```sh
npm ci
npm run dev
```

Для проверки и сборки:

```sh
npm run lint
npm run build
```

## Развёртывание

Дашборд — статическое приложение: настройте корневой каталог сборки `frontend`, команду установки `npm ci`, команду сборки `npm run build` и каталог публикации `dist`. API и база данных для дашборда не нужны. Для публикации в корне или подкаталоге используется относительный базовый путь Vite. Хостинг и автоматический деплой в репозитории пока не настроены.
