# Быстрый запуск учебного приложения

Приложение работает как одностраничный сайт: для уроков, дорожной карты, глоссария и лабораторий отдельная база данных или запущенный сервер не нужны. На подготовку обычно достаточно нескольких минут при установленном Node.js и доступе к npm.

## 1. Установите зависимости и запустите приложение

Нужны Node.js 22 или новее и npm. Выполняйте команды из корня репозитория:

```bash
cd frontend
npm ci
npm run dev
```

Откройте адрес, который Vite напечатает в терминале. Для остановки сервера нажмите `Ctrl+C`. Если вы изменили зависимости в `package.json`, обновите также `package-lock.json`; для обычного запуска повторно используйте `npm ci`.

Для сборки статической версии выполните из каталога `frontend`:

```bash
npm test
npm run lint
npm run typecheck
npm run build
npm run preview
```

Собранные файлы находятся в `frontend/dist`. `preview` показывает локальную production-сборку; его адрес Vite также выведет в терминал.

Motion и GSAP ScrollTrigger отвечают за анимации уроков; PDF.js — за отображение выбранной книги. Значки берутся из React Icons.

## 3. Как добавить или изменить материал

Откройте `frontend/src/data/course.json`. У курса есть метаданные и массив модулей `modules`; каждый модуль содержит темы `topics`. В теме находятся `summary`, массив сцен `scenes`, термины `terms`, поисковые фразы `youtube.queriesRu` и `youtube.queriesEn`, а также вопросы `quiz`. Каждая сцена содержит заголовок `title` и текст `body`; у вопроса указываются варианты `options`, индекс правильного ответа `answer` (с нуля) и объяснение `explanation`.

При добавлении темы задайте уникальный `id`, сохраните корректный JSON и не меняйте идентификаторы без необходимости: интерфейс использует их для связи с состоянием пользователя. Добавьте рекомендуемое видео для главы в `chapterVideos` в `lessonVideos.js`. `pdfPage` обозначает физическую страницу PDF, начиная с первой страницы файла; это число может отличаться от напечатанного номера страницы.

Для нового шага дорожной карты добавьте тему с постоянным `id` в `guide.js`, объяснение и лабораторию в `lessons.js` или `extendedLessons.js`, подробности и вопрос с вариантами ответа в соответствующий `lessonDetails*.js`, пошаговый разбор в `lessonWalkthroughs*.js`, рекомендацию видео в `lessonVideos.js`, а минимум два тематических источника с подсказками для чтения — в `resources.js`. Аналогичные данные трека Windows находятся в `windowsSecurity.js` и связанных файлах подробностей, пошаговых разборов, видео и источников.

Для новой темы AZ-104 положите урок, подробности, пошаговый разбор и источники в модули `azureAdmin*.js` и подключите их в `trackContent.js`: тема считается опубликованной, когда у неё есть урок, а `azureAdmin.js` сам переносит её из списка «в разработке» в карту трека. Для нового отдельного трека добавьте описание по образцу `azureAdmin.js`, запись в `tracks.js`, данные в `trackContent.js`, секцию в `App.jsx` и включите курс в список тем теста `tests/curriculum.test.mjs`. Указывайте тип, язык и условия доступа источника; проверяйте его назначение и ссылку. `npm test` проверяет соответствие тем, уроков, тестов, видео и источников, а также сохранение прежних идентификаторов прогресса.

## 4. Книга и видео

В разделе книги выберите PDF на своём устройстве. Полный файл книги в репозитории не опубликован: читалка обрабатывает выбранный файл в браузере, поддерживает оглавление и поиск. После перезагрузки страницы файл нужно выбрать снова; последняя страница запоминается локально. Оригинал книги на английском, а материалы приложения являются русскоязычным сопровождением, а не полным переводом.

У каждой темы дорожной карты и главы книги есть рекомендация видео на английском со ссылкой на источник подборки. В главе книги можно подставить рекомендацию или найти свой ролик по русским и английским поисковым фразам, вставить URL или ID и сохранить собственные таймкоды. На страницах дорожной карты плеер загружается только после нажатия; в главе ранее выбранный и сохранённый ролик может загрузиться при повторном открытии. Для просмотра нужен интернет, а доступность зависит от YouTube и автора ролика; старые версии интерфейсов могут отличаться от современных.

Уроки и главы открываются на отдельных адресах, например `?lesson=ip-addressing` и `?chapter=compute`; их можно обновлять и отправлять другим. Прогресс, выбранная тема и страница PDF хранятся в браузере на устройстве и не синхронизируются между устройствами. Ответы тестов после перезагрузки не сохраняются.

## 5. Тренажёры и лаборатории

В разделе «Тренажёры» доступны калькулятор IPv4/CIDR, упрощённая модель сетевого пути и правил firewall и виртуальный терминал с ограниченным набором команд. Терминал не запускает команды операционной системы, а сетевая модель не отправляет настоящие пакеты и не является эмулятором Cisco.

Для реальной практики с Cisco Packet Tracer откройте инструкцию в этом разделе, перейдите на официальный сайт Cisco Networking Academy и выполните актуальные требования по регистрации и установке. Доступность портала и программы зависит от Cisco. Не устанавливайте Packet Tracer из непроверенных источников. Собственные команды для Windows и других систем выполняйте только в изолированной учебной среде; облачные лаборатории могут требовать лицензии и оплаты.

## 6. Статический хостинг

Используйте `frontend` как рабочий каталог сборки, `npm ci` для установки и `npm run build` для сборки; публикуйте содержимое `frontend/dist`. Vite настроен с `base: './'`, чтобы ресурсы корректно разрешались как в корне сайта, так и в подкаталоге, например на GitHub Pages. Сервер из каталога `server` не требуется для учебного интерфейса.
