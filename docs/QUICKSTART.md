# Быстрый запуск учебного приложения

Приложение работает как одностраничный сайт: для уроков, дорожной карты, глоссария и лабораторий отдельная база данных или запущенный сервер не нужны. На подготовку обычно достаточно нескольких минут при установленном Node.js и доступе к npm.

## 1. Установите зависимости и запустите приложение

Нужны Node.js 22 или новее и npm. Выполняйте команды из корня репозитория:

```bash
cd frontend
npm ci
npm run dev
```

Откройте адрес, который Vite напечатает в терминале. Для остановки сервера нажмите `Ctrl+C`. Если вы изменили зависимости в `package.json`, обновите также `package-lock.json`; для обычного запуска повторно используйте `npm ci`.

Для сборки статической версии выполните из каталога `frontend`:

```bash
npm run build
npm run preview
```

Собранные файлы находятся в `frontend/dist`. `preview` показывает локальную production-сборку; его адрес Vite также выведет в терминал.

## 2. Где что находится

```text
books-mysql/
├── docs/QUICKSTART.md                   # эта инструкция
├── frontend/
│   ├── index.html                      # точка входа страницы
│   ├── package.json                    # зависимости и команды
│   ├── vite.config.js                  # настройки Vite, включая относительный base
│   └── src/
│       ├── main.jsx                    # запуск React
│       ├── App.jsx                     # разделы и навигация приложения
│       ├── index.css                   # общая дизайн-система и темы
│       ├── course.css                  # оформление интерактивных уроков
│       ├── book-reader.css             # оформление читалки PDF
│       ├── data/
│       │   ├── course.json             # модули, сцены, термины, видео-поиск и квизы книги
│       │   ├── guide.js                # дорожная карта, глоссарий, лабы и сертификаты
│       │   ├── lessons.js              # уроки дорожной карты
│       │   └── bookGuide.js            # путеводитель по оригинальной книге
│       └── components/
│           ├── BookCourse.tsx          # выбор модулей и глав
│           ├── InteractiveLesson.tsx   # интерактивный урок, Motion и GSAP ScrollTrigger
│           ├── VideoPlayer.tsx         # YouTube-поиск и плеер выбранного ролика
│           ├── Roadmap.jsx             # этапы и уроки дорожной карты
│           ├── BookReader.jsx          # локальное чтение PDF через PDF.js
│           ├── Glossary.jsx            # поиск и категории терминов
│           └── ui/button.tsx           # переиспользуемая кнопка в стиле shadcn/ui
├── docs/YOUTUBE_SEARCH.md              # запросы для всех глав курса
└── server/                             # прежний API; для учебного приложения не требуется
```

React с Vite отвечает за интерфейс, TypeScript используется для новых компонентов. Tailwind CSS и переиспользуемые элементы в стиле shadcn/ui помогают оформлять интерфейс. Motion и GSAP ScrollTrigger отвечают за анимации уроков; PDF.js — за отображение выбранной книги. Значки берутся из React Icons.

## 3. Как добавить или изменить материал

Откройте `frontend/src/data/course.json`. У курса есть метаданные и массив модулей `modules`; каждый модуль содержит темы `topics`. В теме находятся `summary`, массив сцен `scenes`, термины `terms`, поисковые фразы `youtube.queriesRu` и `youtube.queriesEn`, а также вопросы `quiz`. Каждая сцена содержит заголовок `title` и текст `body`; у вопроса указываются варианты `options`, индекс правильного ответа `answer` (с нуля) и объяснение `explanation`.

При добавлении темы задайте уникальный `id`, сохраните корректный JSON и не меняйте идентификаторы без необходимости: интерфейс использует их для связи с состоянием пользователя. `pdfPage` обозначает физическую страницу PDF, начиная с первой страницы файла; это число может отличаться от напечатанного номера страницы.

## 4. Книга и видео

В разделе книги выберите PDF на своём устройстве. Полный файл книги в репозитории не опубликован: читалка обрабатывает выбранный файл в браузере, поддерживает оглавление и поиск. После перезагрузки страницы файл нужно выбрать снова; последняя страница запоминается локально. Оригинал книги на английском, а материалы приложения являются русскоязычным сопровождением, а не полным переводом.

Для каждого раздела подготовлены поисковые фразы на русском и английском. Поисковая ссылка открывает результаты YouTube. Чтобы встроить конкретный ролик, вставьте его URL или ID в видеоплеер урока; используйте собственные проверенные таймкоды. Поисковые запросы и квизы работают из локального файла данных, но для открытия YouTube и просмотра видео нужен интернет.

Прогресс и настройки хранятся в браузере на устройстве и не синхронизируются между браузерами или устройствами.

## 5. Статический хостинг

Используйте `frontend` как рабочий каталог сборки, `npm ci` для установки и `npm run build` для сборки; публикуйте содержимое `frontend/dist`. Vite настроен с `base: './'`, чтобы ресурсы корректно разрешались как в корне сайта, так и в подкаталоге, например на GitHub Pages. Сервер из каталога `server` не требуется для учебного интерфейса.
