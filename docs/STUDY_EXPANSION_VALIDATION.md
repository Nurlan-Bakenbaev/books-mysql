## Автоматическая проверка

Из `frontend`: `npm test`, `npm run lint`, `npm run typecheck`, `npm run build`.
После завершения сборки: `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium PLAYWRIGHT_SKIP_BUILD=1 npm run test:e2e`.
Не запускать preview-тесты одновременно со сборкой: Vite заменяет `dist`.

Unit-проверки охватывают сохранность baseline IDs, runnable существующие примеры, структуру всех курсов, честное отсутствие неподходящих видео, перестановку ответов, invalid import и частичный storage failure. Браузерные проверки охватывают маршруты всех 38 основных и 20 сетевых уроков, desktop/mobile, темы, axe, navbar, якоря, чтение после reload, историю, импорт, экспорт, reduced-motion и паузу.

## Ограничения

Это проверка приложения и его данных. Полное выполнение всех лабораторий Windows Server, гипервизоров, сетевого оборудования и облачных подписок не проводилось. Эти стенды требуют отдельных VM, лицензий/аккаунтов и ресурсов. Проверка формы урока не является внешней оценкой педагогического качества.

YouTube и Microsoft Learn возвращали запрет CONNECT 403 от сетевой policy этой cloud-среды. Форматы URL, локальные связи и источник video ID проверены; live доступность всех внешних страниц и воспроизведение всех роликов не подтверждены. GitHub доступен через существующую platform authentication. GitHub API отдельно заблокирован policy; workflow можно проверять по публичной странице Actions.

Сборка предупреждает о крупных chunks и устаревшей базе Browserslist. Lockfile сохранён; полный разделённый по курсам data loading в эту реализацию не входит.
