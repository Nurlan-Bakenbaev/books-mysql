# Видео: English / Русский

Для 131 из 134 уроков подобрано английское видео по теме. При открытии другого урока и после перезагрузки выбирается English. Выбор языка действует только внутри открытого урока и не меняет сохранённый учебный прогресс. Для трёх новых тем Security+ отдельное встроенное видео не подобрано.

Для 29 уроков подобраны русскоязычные материалы: отдельные видео и полноценные видеокурсы. Они не являются переводами английских роликов. Поле `focus` в `frontend/src/data/russianLessonVideos.js` и текст карточки указывают, какую часть темы дополняет материал. Например, курс PowerShell не выдаётся за руководство по AD, Docker — за инструкцию Azure Container Apps, а Prometheus — за обучение SIEM. Длительность русских видео не заявляется без подтверждения; плейлисты явно подписаны как видеокурсы.

Для остальных 105 уроков русского варианта пока нет; у 102 из них доступно английское видео. Для всех 37 уроков Security+ дополнительно дана ссылка на страницу видеокурса Professor Messer с указанием темы, которую нужно найти. Это ссылка на курс, а не утверждение о проверенном индивидуальном видео URL для каждого урока. После выбора «Русский» сайт прямо сообщает, если отдельный русскоязычный материал не подобран. Поисковая выдача YouTube и случайный ролик не используются вместо подобранного материала.

Playwright проверяет переключение одного плеера, английский вариант при перезагрузке и навигации, отсутствие подмены при недостающем переводе, клавиатуру и доступность. Сетевые обращения к внешнему видеохостингу в этих тестах исключены; они не доказывают воспроизведение видео.
