# Интеграция курса «Фундаментальный Computer Science: Архитектура, ОС и Сети»

Курс `computer-technologies` полностью заменён новой программой. Прежние восемь уроков и их идентификаторы удалены из опубликованного маршрута; вместо них доступны три последовательных модуля и шесть уроков:

| Модуль | Уроки |
| --- | --- |
| Архитектура ЭВМ | `csf-cpu-architecture`, `csf-memory-hierarchy` |
| Операционные системы | `csf-kernel-processes`, `csf-memory-ipc-filesystems` |
| Компьютерные сети и Web | `csf-network-models-routing`, `csf-transport-web-rest` |

Каждый урок содержит подробную теорию, схему, безопасную локальную лабораторию, критерий проверки, диагностику, задания и первоисточники. Практика выполняется в Linux VM с Bash и Python 3; она не требует изменения firmware, production-сети или рабочих данных.

## Видеоматериалы

Основные русскоязычные видео из предоставленной программы встроены в соответствующие уроки. Дополнительные видео перечислены среди учебных материалов. Все исходные `http://`-ссылки нормализованы до `https://`.

Видео дополняют, но не заменяют документацию. Архитектурные утверждения сверяются с RISC-V ISA, CS:APP и OSTEP; темы памяти и файловых систем — с документацией Linux; сетевые и Web-темы — с RFC 1122, RFC 8200, RFC 9110 и MDN.

## Связь с маршрутом системного администратора

Узел аппаратной базы карты ведёт на `csf-cpu-architecture`, а узел устройства ОС — на `csf-kernel-processes`. Остальные курсы и профильный README при замене не изменялись.
